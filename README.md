# 🎬 Movie Ticket Booking System

A **C-based Movie Ticket Booking System** developed using Data Structures concepts. The system allows users to view movies and seats, book and cancel tickets, store booking records, and manage a waiting queue when seats are unavailable.

### Features

* 🎥 View available movies and ratings
* 💺 View seat availability
* 🎟️ Book movie tickets
* ❌ Cancel bookings
* 📋 Display booking details
* ⏳ Maintain a waiting queue
* 🔗 Uses Linked List for booking management
* 📦 Uses Array for movies and seats
* 🚶 Uses Queue for the waiting list

### Data Structures Used

* **Array** – Movies and seat management
* **Linked List** – Booking records
* **Queue** – Waiting list
* **Structures** – Organizing movie, booking, and customer data

### Technology

* **Language:** C
* **Concepts:** Data Structures, Arrays, Linked Lists, Queues, Dynamic Memory Allocation

### Complexity

The overall worst-case time complexity is **O(n)**, where `n` is the number of bookings.
